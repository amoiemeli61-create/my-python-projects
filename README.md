### Simple Calculator 🧮

یه ماشین‌حساب با پایتون که این عملیات رو پشتیبانی می‌کنه:

- جمع (+)
- تفریق (-)
- ضرب (*)
- تقسیم (/)
- تقسیم صحیح (//)
- باقی‌مانده (%)
- توان (**)
- عملگرهای مقایسه: `>`, `<`, `>=`, `<=`, `==`, `!=`

**امکانات ویژه:**
- مدیریت تقسیم بر صفر
- مدیریت عملگر نامعتبر

این پروژه برای تمرین مبانی پایتون ساخته شده.
