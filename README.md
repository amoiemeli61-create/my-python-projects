### Simple Calculator 🧮

یک ماشین‌حساب با پایتون که عملیات زیر را پشتیبانی می‌کند:

* جمع (+)
* تفریق (-)
* ضرب (*)
* تقسیم (/)
* تقسیم صحیح (//)
* باقی‌مانده (%)
* توان (**)
* عملگرهای مقایسه: `>`, `<`, `>=`, `<=`, `==`, `!=`

**امکانات ویژه:**

* مدیریت تقسیم بر صفر
* مدیریت عملگر نامعتبر

**مفاهیمی که تمرین شد:**

* متغیرها
* شرط‌ها
* عملگرها
* مدیریت خطاهای منطقی
